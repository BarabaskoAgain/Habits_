## Задачи

### 1. Модель дня (миграция v2 → v3)

Новое хранилище `@dayEntries`: `Record<date, DayEntry>`.

```ts
export type DayState = 'normal' | 'sick' | 'vacation' | 'skipped';

export interface DayEvent {
  id: string;
  category: 'food' | 'movie' | 'workout' | 'work' | 'travel' | 'other';
  title: string;             // "Кафе Coffee Cake"
  rating: number;            // 1..10
  note?: string;
  createdAt: string;
}

export interface DayEntry {
  date: string;              // ISO YYYY-MM-DD
  state: DayState;
  note?: string;             // текстовая заметка дня
  voiceNoteUri?: string;     // локальный путь к аудио
  voiceNoteDuration?: number;// сек
  events?: DayEvent[];
}
```

Миграция `storage`: `version: 3`, добавляет пустой `@dayEntries: {}`.

### 2. Issue #18 — больничный/отпуск

**API:**

`src/utils/streak.js` — `isSkipDay(habit, date, dayEntry)`:
- Возвращает `true` если:
  - `date` не в `habit.activeDays` (уже было в S2), **или**
  - `dayEntry?.state === 'sick' || 'vacation'`.

**UI:**
- В шапке главного экрана рядом с датой — маленький бейдж "Обычный день" / "🤒 Болею" / "✈️ Отпуск".
- Тап на бейдж → bottom sheet "Отметить день" с 4 радио: `Обычный / Болею / Отпуск / Пропущено`.
- Пометка распространяется только на выбранный день.
- Возможность отметить **диапазон** ("болею с 3 по 10 октября") через отдельный экран `MarkPeriodScreen`.

**Визуализация в статистике:**
- В heatmap sick-дни рисуются иконкой 🤒 (уменьшенной прозрачностью).
- В расчёте `plan` за период — sick/vacation дни исключаются, но фактические выполнения — учитываются (пользователь мог всё же что-то сделать).

### 3. Issue #19 — заметка дня (текст + голос)

**Экран `DayJournalScreen`:**
- Дата, состояние дня.
- Textarea для заметки (до 500 симв).
- Кнопка "Запись голосом" — использует `expo-audio` (пакет добавить в `package.json`).
- Индикатор длительности при записи, кнопка "Стоп".
- Воспроизведение записанного (Play/Pause).
- Удаление заметки.

**Технически:**
- `src/services/voiceNote.js`:
  - `start()` → путь к файлу в `FileSystem.documentDirectory + 'voice/'`.
  - `stop()` → duration.
  - `play(uri)`, `stop()`.
  - Формат: m4a (Android/iOS-совместимый).
- Автосохранение заметки при закрытии экрана.

### 4. Issue #20 — события дня + сводки

**Экран `AddDayEventScreen`:**
- Выбор категории (6 категорий с иконками).
- Название (обязательное, до 100 симв).
- Оценка 1..10 (сегментированный слайдер с эмодзи).
- Заметка (до 200 симв).
- Кнопка "Сохранить".

**Экран `DayJournalScreen` показывает список событий дня.**

**Сводка за неделю/месяц/год:**

Новая вкладка внизу — `Дневник` (третья вкладка рядом с Главная / Статистика).

На вкладке — переключатель Неделя / Месяц / Год. Показывает:
- Топ-5 самых высоко оценённых событий.
- Средняя оценка по категориям.
- Диаграмма распределения (сколько событий каких категорий).
- Sick-дни в периоде, дни без записей.
- Кнопка "Экспортировать сводку в текст" (через `Share`).

**Компонент `src/components/summary/`:**
- `TopEventsList.js`
- `CategoryPie.js`
- `MoodTimeline.js` (график средней оценки по дням)

## Definition of Done

- [ ] Пользователь может отметить сегодня как "болею" за 2 тапа.
- [ ] В воскресенье sick-дни не ломают серию "с понедельника до пятницы".
- [ ] На heatmap sick-дни визуально помечены.
- [ ] Заметка дня (текст) сохраняется и восстанавливается при следующем открытии.
- [ ] Голосовая заметка записывается, воспроизводится, удаляется.
- [ ] Добавление события ("Кафе X, 8/10") — за 3 тапа.
- [ ] Экран сводки за неделю показывает топ-5 событий и средние оценки.
- [ ] Миграция v2 → v3 применяется, старые данные не теряются.
- [ ] Тесты зелёные.
- [ ] PR открыт, DoD-чеклист.

## Критерий 10/10

1. Владелец в пятницу пометил "болею с ср по пт" — в воскресенье увидел, что серия не сброшена.
2. Наговорил голосом заметку в четверг — в воскресенье прослушал.
3. За неделю накидал 5 событий (2 кафе, фильм, тренировка, встреча) — в сводке за неделю сразу видит топ-3 по оценке.
4. Никакие миграции не потеряли старые completions.
5. Голосовая заметка не жрёт батарею при неактивной записи, файлы хранятся в defensible-месте.

Если какая-то из этих механик крашится — не 10/10.
