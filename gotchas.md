# Gotchas — Habits

Ошибки, на которые уже наступили, и правило, чтобы не повторить.

- **pg-mem ≠ Postgres.** `CREATE TABLE IF NOT EXISTS` падает в pg-mem, если таблица есть; `INT[] DEFAULT '{…}'`
  приходит строкой (пиши `ARRAY[…]`); нет `DO $$`, `IS DISTINCT FROM`, `AT TIME ZONE`, `setval`, `TRUNCATE`;
  `BEGIN/ROLLBACK` через `pool.connect()` не откатывает. → Перенос данных — в `NNN_*.mjs`; API-тесты гонять и на
  настоящем Postgres (`TEST_DATABASE_URL`, скрипт с embedded-postgres).
- **embedded-postgres на этой машине.** `initdb --encoding=UTF8` падает на кириллическом имени пользователя Windows.
  → Кластер в кодировке ОС, тестовые базы `CREATE DATABASE … ENCODING 'UTF8' TEMPLATE template0 LC_COLLATE 'C' LC_CTYPE 'C'`.
- **Экран привычки не обновлялся после сохранения.** `load()` вызывал `render()` (только вкладку). → после загрузки
  всегда `rerender()` (вкладка + открытый экран).
- **Очередь отметок после ошибки.** `.then` на отклонённом промисе не вызывается — следующий тап по той же клетке
  не уходил. → цепочку начинать с `.catch(() => {})`, после ошибки — повторная загрузка с сервера.
- **«Сегодня» на клиенте ≠ на сервере.** Сервер считает по Киеву, клиент по поясу устройства. → `todayKey()` через
  `Intl` с `Europe/Kyiv` в `app.js`, на сервере `kyivDay()`.
- **Service worker.** `cache.addAll` атомарный: один 404 в SHELL — новый SW не ставится, приложение молча старое.
  → тест `test/fmt.test.js` сверяет SHELL с файлами; при деплое поднимать `CACHE_VERSION`.
- **pg-mem не соблюдает условие в `UPDATE … WHERE value + $3 <= $4`** при параллельных запросах и не парсит
  `$3::float8`. → гонки проверять только на настоящем Postgres (тест помечен skip для pg-mem).
- **«Назад» на телефоне.** Каждый слой (шторка, экран) без записи в истории → «Назад» уводил на /login.html.
  → одна запись `overlay` на все слои, `popstate` закрывает верхний; закрытие кодом — отложенный `history.back()`
  с `ignorePop`, чтобы повторное открытие шторки не съедало запись.
- **Перерисовка шторки по ответу сервера стирает ввод.** → обновлять только итог/полоску, а не всю шторку.
- **Playwright MCP-мост тут не подключён.** → E2E через `playwright-core` + `channel: 'chrome'` из scratchpad.
- **Python в Git Bash висит.** Python (через python -c и heredoc) в Git Bash на этой машине висит: стаб Microsoft Store ждёт ввод. Правки файлов делать через Edit или node -e, а не через python.
